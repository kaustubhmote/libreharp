# Third-party components

LibreHarp's new Python source is distributed under GPL-3.0-or-later; see LICENSE.

The bundled Harper language server is Harper 3.0.0 from Automattic/harper, distributed under Apache-2.0. Its license and release provenance are included in `vendor/harper/`. The unmodified `default_config.json` rule catalog is from the same release. Source: https://github.com/Automattic/harper/tree/v3.0.0.

The previous LibreHarper/WriterAgent project informed the requirements and integration review. Its Python source is not included in this independent implementation.
